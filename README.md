# Log Parser

Парсер логов на Python.

## Что делает

Читает файл access.log и выводит топ-10 IP по количеству запросов.

## Как работает

1. Открывает файл.
2. Читает построчно.
3. Берёт первый элемент в строке (IP).
4. Считает через словарь.
5. Сортирует и выводит топ-10.

## Как запустить

Скачай пример лога:
```bash
wget https://raw.githubusercontent.com/linuxacademy/content-elastic-log-samples/master/access.log
```

Запусти:
```bash
python3 log_parser.py access.log
```

**Важно:** в примере IP находится на позиции `0`. Если у тебя другой формат — поменяй индекс в строке `ip = log.split()[0]`.

## Пример вывода

```
83.149.9.216 5
192.168.1.1 3
```
